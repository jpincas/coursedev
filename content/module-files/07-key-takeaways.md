# Key Takeaways: Files

This module has covered a fundamental shift in how you work with AI. Here are the essential principles to carry forward.

## 1. Files, Not Chat

The deliverable is the point, not the conversation.

Chat is for communication. Files are for work. If you are copy-pasting from chat, you are doing it wrong.

## 2. Plain Text Is AI-Native

Understand the format spectrum. Plain text (CSV, Markdown, code) is processed directly by AI with no conversion loss. Binary formats (Excel, PowerPoint, PDF) work but require conversion. When you have a choice, prefer plain text.

Markdown is the lingua franca of AI. Learning basic Markdown syntax is the single highest-ROI investment for AI work.

## 3. Provide, Don't Describe

Upload your actual data. Do not summarise it in text.

AI works better with the real information than with your description of it. Eliminate the game of telephone.

## 4. The Productive Spiral

Output files become input files for the next round. Quality compounds with each cycle. Every document AI creates is a future input file. Build your work as a spiral, not a series of isolated tasks.

## 5. Organisation Is Leverage

An organised file system is not just tidy -- it is a library of context for every future AI task. Descriptive names, logical folders, and consistent formats make every AI interaction better.

## 6. Ground with Specifics

Your style guide, your templates, your data, your examples. AI produces generic output without grounding. Provide your specific materials to get output that fits your context.

```callout

```

## The Practical Test

For your next AI task, ask yourself:

- Am I copy-pasting from chat? -- Request a file instead
- Am I describing my data? -- Upload it instead
- Is the output too generic? -- Provide grounding materials
- Am I reformatting constantly? -- Request the right format upfront
- Am I starting from scratch each time? -- Use previous outputs as inputs
- Are my files named and organised? -- Clean up before you start
