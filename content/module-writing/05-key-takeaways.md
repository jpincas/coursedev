# Key Takeaways

## What You've Learned

**Sectional drafting beats single-prompt generation.**

Create an outline. Expand sections individually with specific constraints. Merge and smooth. This produces focused, coherent documents.

**Style transfer requires explicit scaffolding.**

Give AI 2-3 samples of your writing. Ask it to analyse your style. Create a reusable style card or use the EchoWriting technique with 15-20 samples for persistent style prompts.

**Data analysis workflow: clean, upload, describe, then query.**

Prepare clean data. Upload it. Ask AI to describe what it sees first. Then ask specific analytical questions. Inspect generated code.

**Verification is not optional.**

AI analysis appears sophisticated but can be fundamentally wrong. Inspect code. Verify citations. Check claimed patterns exist. Run domain experts' eyes over output.

## What Connects Forward

The techniques you've learned here — sectional work, style encoding, verification — apply to the delegation mindset you'll explore next.

You delegate tasks to AI. You verify the output. You own the result.

The pattern is the same whether you're writing a report, analysing a dataset, or orchestrating a multi-step workflow.

## Practical Next Steps

**For writing:**
- Create a style card encoding your preferences
- Try sectional drafting on your next long document
- Give AI samples of your best writing before starting

**For data analysis:**
- Clean one dataset and upload it to Claude or ChatGPT
- Ask it to describe the data before running analysis
- Inspect the generated code for at least one analysis

**For both:**
- Build verification into your workflow from day one
- Treat AI output as a draft, not a deliverable
- Remember: you own the result, AI accelerates the work
